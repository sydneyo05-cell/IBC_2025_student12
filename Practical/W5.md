# 4.3 GC content from fasta
``` Python
with open("Turkey_transcripts_15.fasta", "r") as infile, open("gc_content.txt", "w") as outfile:
    for line in infile:
        line = line.rstrip() # Got this code from the note in class 
        
        if line.startswith(">"):
            gene_id = line.split()[0][1:]
        else:
            seq = line
            
            gc = (seq.count("G") + seq.count("C")) / len(seq) # code from class 
            
            outfile.write(gene_id + "\t" + str(gc) + "\n") # code from class 
```
