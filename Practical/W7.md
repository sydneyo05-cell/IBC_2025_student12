### 1. Read the file pubmed_results.txt, and extract all the US ZIP codes.
``` python
import re

with open("DataFiles/MapOfScience/pubmed_results.txt", "r") as file:
    text = file.read()

zip_codes = re.findall(r"\b\d{5}\b", text)

print(zip_codes)
```
