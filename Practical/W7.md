### 1. Read the file pubmed_results.txt, and extract all the US ZIP codes.
``` python
import re

with open("DataFiles/MapOfScience/pubmed_results.txt", "r") as file:
    text = file.read()

zip_codes = re.findall(r"\b\d{5}\b", text)

print(zip_codes)
``` 

### 2. Create the lists zip_code, zip_long, zip_lat, and zip_count, containing the unique ZIP codes, their longitudes, latitudes, and counts (number of occurrences in Science), respectively. Hint: Use the csv module to parse the zipcodes_coordinates.txt.
``` python

import csv

# This is setting all the lists and telling the code where I want the output to be 
zip_code = []
zip_long = []
zip_lat = []
zip_count = []

with open("DataFiles/MapOfScience/zipcodes_coordinates.txt", "r") as file:
    reader = csv.reader(file)
    next(reader)

    for row in reader:  # reads each line of code one at a time 
        if row[0] in zip_codes: # conditional statement, checks if zip code is in that row
            zip_code.append(row[0])
            zip_long.append(float(row[2]))
            zip_lat.append(float(row[1]))
            zip_count.append(zip_codes.count(row[0]))
# prints the outcome of the zip code, lat, long, and count

print(zip_code)
print(zip_long)
print(zip_lat)
print(zip_count)
```
