## pch Symbols. The r-charts website has an explanation of how to generate Figure 1 using R. Their way code makes use of the expand.grid() function. Write a script that replicates this figure without using expand.grid(). Include the figure in your markdown document.
```R 
x <- rep(1:5, 6)[1:26]
y <- rep(6:1, each=5)[1:26]

plot(x, y, type="n", axes=FALSE,
     xlab="", ylab="",
     main="Plotting Symbols")

points(x, y, pch=symbols, cex=2)

text(x, y-0.3, symbols)
```
